### 📚 ഉൾപ്പെടുത്തിയിട്ടുള്ള പ്രധാന മോഡ്യൂളുകൾ (Course Modules)

1. **അടിസ്ഥാന നെറ്റ്‌വർക്കിംഗ് & ഇ.എൽ.വി (Basics of Networking & ELV)**:
   - എന്താണ് Extra Low Voltage (ELV / ലൈറ്റ് കറന്റ് സിസ്റ്റംസ്)? 50V AC / 120V DC പരിധി.
   - LAN, WAN, IP Address (IPv4 Classes A, B, C), Subnet Mask, Default Gateway, DNS, DHCP, MAC Address.
   - Active vs Passive Networking Components: Switches (Unmanaged vs Managed, PoE 802.3af/at/bt), Routers, Patch Panels, Server Racks (4U to 42U).
   - Cat6 vs Cat5e vs Fiber Optic (Single-Mode vs Multi-Mode).

2. **സിസിടിവി ക്യാമറ ഇൻസ്റ്റാളേഷൻ ഗൈഡ് (Camera Installation Guide)**:
   - സൈറ്റ് സർവേ & കവറേജ് പ്ലാനിംഗ്.
   - ലെൻസ് ഫോക്കൽ ലെങ്ത് (2.8mm വൈഡ് ആംഗിൾ, 3.6mm/4mm സ്റ്റാൻഡേർഡ്, 6mm ദൂരക്കാഴ്ച).
   - ക്യാമറ മോഡലുകൾ (Dome, Bullet, PTZ, Turret) & IP66/IP67 വാട്ടർപ്രൂഫ് റേറ്റിംഗുകൾ.
   - സ്റ്റെപ്പ്-ബൈ-സ്റ്റെപ്പ് ഫിസിക്കൽ ഇൻസ്റ്റാളേഷൻ, PVC കോൺഡ്യൂട്ട്, വാട്ടർപ്രൂഫ് ജംഗ്ഷൻ ബോക്സ്, O-Ring സീലിംഗ്.

3. **അനലോഗ് vs ഐപി ക്യാമറ (Analogue vs IP Camera)**:
   - RG59 കോക്സിയൽ + BNC കണക്ടർ + DVR vs Cat6 UTP + RJ45 + NVR.
   - 2MP, 4MP, 8MP (4K) റെസല്യൂഷൻ താരതമ്യം.
   - IP Camera Activation: SADP Tool (Hikvision) & ConfigTool (Dahua) ഉപയോഗിച്ച് സ്റ്റാറ്റിക് ഐപി സെറ്റ് ചെയ്യൽ.
   - P2P Cloud (Hik-Connect / DMSS) വഴി മൊബൈലിൽ ലൈവ് വ്യൂ കാണൽ.

4. **RJ45 കളർ കോഡും ക്രിമ്പിംഗും (RJ45 Color Code & Crimping)**:
   - **T-568B & T-568A കളർ കോഡുകൾ:** Pin 1 to Pin 8 പൂർണ്ണ വിശദീകരണം.
   - **ഇന്ററാക്ടീവ് RJ45 വിഷ്വലൈസർ:** ഓരോ വയറിലും ക്ലിക്ക് ചെയ്താൽ സിഗ്നൽ (TX/RX/PoE) കാണാം.
   - Straight-Through vs Crossover കേബിളുകൾ.
   - ക്രിമ്പിംഗ് ടൂൾ ഉപയോഗിച്ച് വയർ മുറിച്ച് ക്രിമ്പ് ചെയ്യുന്ന ഘട്ടങ്ങൾ & ലാൻ ടെസ്റ്റർ പരിശോധന.

5. **കീസ്റ്റോൺ ജാക്ക് & I/O പഞ്ച് ഡൗൺ (Keystone Jack & Punch Down)**:
   - എന്താണ് CAT6 കീസ്റ്റോൺ ജാക്ക് (ഫേസ്പ്ലേറ്റ് / പാച്ച് പാനൽ സോക്കറ്റ്)?
   - സൈഡ് A vs സൈഡ് B കളർ കോഡ് & സ്ലോട്ടുകൾ.
   - 110 Punch Down Impact Tool (ക്രോൺ ടൂൾ) ഉപയോഗിക്കുമ്പോൾ കട്ടിംഗ് ബ്ലേഡ് പുറത്തേക്ക് വെക്കേണ്ടതിന്റെ പ്രാധാന്യം.
   - വയർ പിരി നിലനിർത്തിക്കൊണ്ട് (Twist retention) പഞ്ച് ചെയ്യുന്ന രീതി.

6. **മറ്റ് പ്രധാന ഇ.എൽ.വി സിസ്റ്റങ്ങൾ (Other ELV Systems)**:
   - **Access Control System (ACS):** RFID കാർഡ് റീഡർ, ബയോമെട്രിക് സ്കാനർ, EM Lock (600 lbs Fail-Safe), പുഷ് ടു എക്സിറ്റ് ബട്ടൺ, എമർജൻസി ബ്രേക്ക് ഗ്ലാസ്.
   - **Fire Alarm System:** കൺവെൻഷണൽ vs അഡ്രസ്സബിൾ ഫയർ അലാറം, സ്മോക്ക് ഡിറ്റക്ടർ, ഹീറ്റ് ഡിറ്റക്ടർ, MCP, FP200 ഫയർ കേബിൾ.
   - **Public Address (PA System):** 100V ലൈൻ ട്രാൻസ്ഫോർമർ ഉള്ള സീലിംഗ് സ്പീക്കറുകൾ, ആംപ്ലിഫയർ, സോൺ സെലക്ടർ.
   - **Video Door Phone (VDP) & Intercom.**

7. **കമ്പ്യൂട്ടർ ഹാർഡ്‌വെയർ അടിസ്ഥാനങ്ങൾ (Basics of Computer Hardware)**:
   - മദർബോർഡ് ഘടന (CPU Socket LGA vs AM4/AM5, RAM DIMM, PCIe x16, M.2 NVMe, Front Panel JFP1).
   - പ്രോസസ്സർ (Cores, Threads, Cache, Thermal Paste & Cooler).
   - റാം (DDR4 vs DDR5, Slot 2 & Slot 4 Dual Channel Rule).
   - സ്റ്റോറേജ് താരതമ്യം: HDD (120 MB/s) vs SATA SSD (500 MB/s) vs M.2 NVMe SSD (7000 MB/s).
   - SMPS പവർ സപ്ലൈ: വാട്ടേജ്, 80 Plus സർട്ടിഫിക്കേഷൻ, കണക്ടറുകൾ.
   - ട്രബിൾഷൂട്ടിംഗ്: No Display പരിഹാരം (RAM റബ്ബർ ഇറേസർ ക്ലീനിംഗ്), CR2032 ബാറ്ററി & BIOS റീസെറ്റ്, ഹീറ്റിംഗ് പ്രശ്നങ്ങൾ.
